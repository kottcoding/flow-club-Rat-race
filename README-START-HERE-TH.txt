FLOW CLUB — MASTER COMBINED V2 — 21 พฤศจิกายน 2569

ใช้ ZIP ชุดนี้ชุดเดียว: รวม Master + ป้ายประเภทอุปกรณ์ + คำแนะนำก่อนเข้า Master
ไม่จำเป็นต้องติดตั้ง ZIP Master และ Device ก่อนหน้าซ้ำ
เป็นแพตช์สำหรับโปรเจกต์ Flow Club เดิมรุ่นล่าสุด ไม่ใช่โปรเจกต์เต็ม

เพิ่มใน V2
- ผู้ได้รับสิทธิ์ Master บน PC หรือแท็บเล็ต/iPad เข้าได้ตามปกติ
- บนมือถือ แสดงคำแนะนำให้ใช้จอใหญ่หรือหมุนแนวนอน พร้อม เข้าใช้งานต่อ และ ยกเลิก
- ถ้าตรวจจับประเภทอุปกรณ์ไม่ได้ จะแนะนำการใช้จอใหญ่และยังเข้าใช้งานต่อได้
- ตรวจอุปกรณ์จริงของเบราว์เซอร์เมื่อกดเข้า Master ไม่ใช้ค่าของอุปกรณ์เก่าที่บัญชีเคยใช้
- กดยกเลิกหรือ Escape ปิดคำแนะนำและยังอยู่เกมเดิม ไม่มีการเริ่มติดตามผู้เล่น
- ตรวจสิทธิ์ผู้สอนเช่นเดิม ไม่มีการให้สิทธิ์อัตโนมัติเพราะใช้อุปกรณ์จอใหญ่
- คำแนะนำแสดงทุกครั้งที่ขอเข้า Master บนมือถือหรืออุปกรณ์ไม่ทราบประเภท

วิธีติดตั้ง
1. สำรองไฟล์โปรเจกต์เดิม
2. แตก ZIP ชุดนี้ แล้วนำ app, components, lib, db และ tests วางทับในรากโปรเจกต์เดิม
3. ถ้าเคย Execute db/004-teaching.sql แล้ว ไม่ต้องเพิ่ม SQL อีก
   ถ้ายังไม่เคย: Cloudflare D1 > ฐานข้อมูลที่แอปใช้ > Console แล้ว Execute คำสั่งใน db/004-teaching.sql
   รายละเอียดอยู่ใน README-MASTER-TH.txt
4. Commit ไฟล์ขึ้น GitHub เดิม ให้ Cloudflare Build และ Deploy ตามระบบเดิม
5. ให้ผู้เล่นทุกคนรีเฟรชหน้าเว็บ

ลองหลังติดตั้ง
- เปิดการสอน ให้สิทธิ์ผู้เล่น แล้วลองเข้า Master จาก PC / tablet และมือถือ
- มือถือ: กด ยกเลิก ต้องยังอยู่เกมของตัวเอง; กดเข้าอีกครั้งแล้ว เข้าใช้งานต่อ ต้องเปิด Master แบบดูอย่างเดียว
- ลองหมุนจอและสลับการแสดงผลระหว่างปรับตามจอฉันกับจำลองหน้าจอผู้เล่น
- ถอนสิทธิ์ขณะเปิดคำแนะนำ ผู้เล่นต้องไม่สามารถเข้า Master ได้

การตรวจจับอุปกรณ์เป็นค่าประมาณ ยังไม่ได้ยืนยันกับอุปกรณ์จริงทุกรุ่น
ชุดทดสอบระบบเดิมและ API รวม 19 รายการผ่าน แต่ไม่ใช่การทดสอบ UI popup บนมือถือจริง
ยังไม่ได้ Deploy Production ให้โดยอัตโนมัติ
