# Flow Club

เว็บเกมการเงินภาษาไทย / English สำหรับ 2–6 คนต่อห้อง ไม่ใช้บัญชีผู้เล่น สร้างด้วย React + Vinext + Cloudflare Workers + D1

## เริ่มพัฒนา

ต้องใช้ Node.js 22.13+ และ pnpm

```sh
pnpm install
pnpm build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_aspiring_dragon_man.sql
pnpm dev
```

รัน migration ครั้งเดียวต่อฐานข้อมูลใหม่ เปิด URL ที่ dev server แสดง ทดสอบหลายคนด้วยคนละ browser profile หรือคนละเครื่องที่เข้าถึง server ได้ คนละแท็บในเบราว์เซอร์เดียวกันใช้ที่นั่งเดียวกัน

```sh
node --test tests/game.test.mjs
node node_modules/typescript/bin/tsc --noEmit
```

## โครงสร้าง

- `lib/game.mjs`: กติกา ตัวเลขอาชีพ การ์ด และเครื่องคำนวณฝั่งเซิร์ฟเวอร์
- `app/api/game/route.js`: API สร้าง/เข้าห้อง/เล่น ใช้ D1 และ optimistic concurrency (revision) ป้องกันคำสั่งซ้ำ
- `app/page.jsx`: หน้าห้อง กระดาน SVG การเงิน การคำนวณ และภาษาเฉพาะผู้เล่น
- `app/globals.css`: responsive styling
- `db/schema.ts` และ `drizzle/`: โครงสร้างและ migration
- `.openai/hosting.json`: binding และ Site identity

สถานะห้องบันทึกใน D1 และซิงก์ด้วย polling ทุก 1.5 วินาที ข้อมูล session ในเบราว์เซอร์เป็น secret แบบสุ่ม เซิร์ฟเวอร์เก็บ hash และไม่ส่งกลับในสถานะห้อง ใช้ server random และตรวจสิทธิ์ทุกคำสั่ง

## ขอบเขตและกติกา

เวอร์ชัน 2 ใช้ Dream 23 รายการและราคาเงินบาทจากรูปกระดาน `20261108_171728.jpg` ของผู้ใช้ พร้อมอาชีพวิศวกรจาก `20261108_172029.jpg` ชื่อภาษาอังกฤษและคำอธิบายสั้นเป็นคำแปล ไม่อ้างว่าเป็นข้อความทางการ ลำดับช่องบนเว็บจัดใหม่ให้ Dream ทั้ง 23 รายการเดินถึงได้

**ยังไม่มีรูปด้านหน้าของการ์ด 4 กองและอาชีพอื่น** อาชีพอีก 5 อาชีพและ Small Deal 8 ใบ, Big Deal 5 ใบ, Doodad 8 ใบ, Market 7 ใบ จึงยังเป็นชุดตัวอย่างและมีป้ายบอกในเว็บ ไม่ได้อ้างว่าตรงกับข้อมูลในกล่องจริง ข้อมูล Dream และวิศวกรมีป้ายอ้างอิงภาพจริง ดูรายละเอียดใน `DATA-REFERENCE.md`

โครงสร้างอ้างอิงแนวคิด CASHFLOW จาก https://richdad.com/cashflow/ และ FAQ https://richdad.com/faqs/ ไม่ใช่ผลิตภัณฑ์ Rich Dad และยังไม่ใช่กติกาทางการครบทุกข้อ

กติกาหลัก: Passive Income ต้องมากกว่าค่าใช้จ่ายเพื่อออก Rat Race; Cash Flow อสังหาริมทรัพย์เป็นยอดสุทธิ; เงินกู้ธนาคารมีค่าใช้จ่ายเดือนละ 10%; หนี้ Mortgage ไม่ลดอัตโนมัติ; Market ทุกคนขายสินทรัพย์ตรงประเภทได้ และหุ้นบางใบอนุญาตให้ซื้อได้; Fast Track ชนะด้วยเพิ่มรายได้ 500,000 บาทหรือซื้อความฝันที่เลือก

รายละเอียดฉบับทดลอง: สุ่มผู้เริ่ม, ไม่มี stock split/ขายสิทธิ์ดีล/ซื้อขายระหว่างผู้เล่น, ค่าใช้จ่ายบังคับกู้อัตโนมัติทีละ 10,000 บาท หาก Cash Flow ติดลบต้องชำระหนี้หรือ restructure (ล้างสินทรัพย์/เงินกู้ธนาคาร เงินสด 0 พัก 3 ตา เก็บหนี้ส่วนตัว) กองการ์ดสับและจั่วไม่ซ้ำจนหมดกองก่อนสับใหม่ Doodad ต้องจ่ายก่อนจบตา คำอธิบายอยู่ในปุ่มวิธีเล่นของเว็บ

## ความเข้ากันได้กับห้องเดิม

ห้องเก่าที่ยังรอเล่นเปลี่ยนเป็นชุดบาทและให้ทุกคนเลือก Dream/กดพร้อมใหม่ โดยเก็บชื่อ Dream เดิมไว้แสดงประกอบ ไม่สลับความฝันตามเลข index เดิม ส่วนห้องที่เริ่มแล้วหรือจบแล้วใช้กติกา หน่วยดอลลาร์ ยอดเงิน และ Dream เดิมจนจบ ไม่แปลงเงินกลางเกม `normalizeRoom()` ทำงานซ้ำได้โดยไม่เปลี่ยนผล และบันทึกผ่าน revision เดิมเพื่อป้องกัน concurrent writes

API mutation ต้องส่ง `clientVersion: 2` เพื่อไม่ให้หน้าเว็บที่แคชโค้ดเก่าส่งตัวเลขหรือ Dream index ผิด เมื่อขึ้นข้อความอัปเดตให้รีเฟรชหน้าเว็บ

## ข้อจำกัดการใช้งาน

- ผู้เล่นที่หลุดต้องกลับด้วยเบราว์เซอร์เดิม ไม่มีระบบยึดที่นั่ง/AI/ข้ามคนที่หายไป
- ล้าง storage หรือเปลี่ยนเครื่องจะสูญเสียสิทธิ์ที่นั่งเดิม
- ห้องไม่ active 24 ชั่วโมงหายจาก lobby แต่ยังเข้าผ่านรหัสได้ ข้อมูลยังไม่ถูกลบอัตโนมัติ
- รุ่นนี้สำหรับกลุ่มเพื่อนทดลอง ยังไม่มีระบบ moderation, password ห้อง หรือ rate limit ตาม IP สำหรับเว็บเปิดขนาดใหญ่
- UI ไม่มี login แต่ Sites ที่เป็น private อาจมี hosting access gate; ต้องตั้ง public access ก่อนให้บุคคลทั่วไปเข้าโดยไม่ login

ทุกจำนวนเป็นเงินจำลอง ไม่มีธุรกรรมเงินจริง ห้องใหม่ใช้ THB ข้อมูลตัวอย่างปรับสเกลจากรุ่นแรก ×10 เพื่อให้อยู่ในช่วงใกล้กับกระดานไทย นี่เป็นการปรับสมดุลเกม ไม่ใช่อัตราแลกเปลี่ยน และไม่ใช่การยืนยันราคาของการ์ดจริง
