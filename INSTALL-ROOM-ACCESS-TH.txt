อัปเดตลิงก์เชิญและล็อกห้อง — 15 พฤศจิกายน 2026

การใช้งาน
- เปิดลิงก์ ?room=เลขห้อง: ถ้ามีชื่อแล้วจะลองเข้าห้องทันที
- ถ้ายังไม่มีชื่อ จะแสดงป๊อปอัปให้กรอกชื่อแล้วกดเข้าร่วม
- ถ้าห้องล็อก ต้องกรอก Pass Unlock เป็นเลข 4 หลัก รองรับ 0123
- ใช้เงื่อนไขเดียวกันทั้งลิงก์ ปุ่มเข้าร่วม และเลขห้อง
- ห้องเต็มหรือเริ่ม/จบเกมแล้ว จะไม่รับผู้เล่นใหม่ สมาชิกเดิมกลับเข้าห้องได้ ไม่ต้องกรอกรหัสซ้ำ
- ผู้สร้างห้องกด 🔓 ในหน้าห้องรอ ใส่รหัสแล้วกดบันทึกและล็อกห้อง ไอคอนเปลี่ยนเป็น 🔒
- กด 🔒 อีกครั้งและยืนยันเพื่อปลดล็อก หากต้องการเปลี่ยนรหัส ให้ปลดล็อกแล้วตั้งใหม่
- ทุกห้องเริ่มจากไม่ล็อก การตั้งล็อกทำได้เฉพาะผู้สร้างในช่วงรอผู้เล่น
- Lobby แสดง 🔒 ข้างชื่อห้องที่ล็อก
- ฟังก์ชันล็อกนี้ควบคุมการเข้าร่วมเป็นผู้เล่น ระบบเข้าชมการแข่งขันเดิมไม่เปลี่ยน
- รหัสเก็บเป็นค่าแฮชพร้อม salt ไม่ส่งรหัสกลับมาที่ผู้เล่นหรือรายการห้อง
- กรอกผิดครบ 5 ครั้งต่อรหัสผู้เล่น จะพักการลอง 1 นาที

วิธีอัปเดต
1. สำรอง repository และ Pull origin ให้เรียบร้อย
2. แตก ZIP คัดลอก app, components, lib, public และ tests ทับใน repository ระดับเดียวกับ package.json
3. Commit เช่น Add invite auto join and room PIN แล้ว Push origin
4. รอ Cloudflare build/deploy สำเร็จ แล้วเปิดเว็บกด Ctrl+F5
5. สร้างห้อง กดแม่กุญแจตั้งรหัส และทดสอบลิงก์เชิญในอีกเบราว์เซอร์หรือหน้าต่างส่วนตัว
6. ทดสอบชื่อว่าง รหัสผิด รหัสถูก และการปลดล็อก

ไม่ต้อง Execute SQL และไม่ต้องแก้ Firebase หรือ wrangler.jsonc
เก็บค่าล็อกใน state ของห้องเดิม ห้องเก่าที่ไม่มีค่าล็อกถือว่าไม่ล็อก
ไฟล์ชุดนี้รวมการแก้เสียงซ้ำล่าสุดและไฟล์ MP3 เพื่อให้ใช้ร่วมกันได้
ทดสอบอัตโนมัติ 24 รายการผ่าน และ production build ผ่าน
ยังไม่ได้ deploy ไปยังเว็บไซต์จริง
