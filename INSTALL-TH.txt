Flow Club Ver 1.00 — ปรับโลโก้และเลขเวอร์ชัน / 24 พฤศจิกายน 2569

เปลี่ยน BETA เป็น Ver 1.00 ที่ส่วนหัวและใช้เลขเดียวกันที่ท้ายหน้า
ขยายโลโก้ ใส่กรอบทองอ่อนและเงานูน ป้ายเวอร์ชันแสดงบนมือถือด้วย
ไม่เปลี่ยนโลโก้กลางกระดาน กติกา ฐานข้อมูล หรือส่วนตัวหมาก Safari

วิธีติดตั้ง (ใช้กับโค้ดล่าสุดที่อัปเดตระบบมือถือ iOS/Android แล้ว)
1. สำรองโปรเจกต์ปัจจุบัน
2. แตก ZIP แล้วนำทั้ง 5 ไฟล์ไปวางตามโฟลเดอร์เดิม:
   app/page.jsx
   components/header-layout.css
   lib/app-version.mjs
   scripts/bump-app-version.mjs
   RELEASE-VERSION.md
3. Commit/push ไป GitHub ที่เชื่อม Cloudflare
4. รอ deployment Success แล้วรีเฟรชหน้าแอป
ไม่ต้องรัน SQL ไม่ต้องแก้ Firebase/wrangler.jsonc

อัปเดตย่อยครั้งถัดไป
รันจากโฟลเดอร์โปรเจกต์:
node scripts/bump-app-version.mjs
จะเปลี่ยน 1.00 เป็น 1.01 และครั้งต่อไปเป็น 1.02
รันครั้งเดียวต่อรุ่นที่เผยแพร่ ไม่รันซ้ำตอน build หรือ deploy retry
รอบนี้เริ่ม 1.00 จึงไม่ต้องรันคำสั่งเพิ่มเลข
API_VERSION และ RULE_VERSION แยกจากเลขเวอร์ชันหน้าจอ

ตรวจสคริปต์เพิ่มเวอร์ชันบนสำเนาแล้ว
ยังไม่ได้ตรวจภาพส่วนหัวบนอุปกรณ์จริง
