Flow Club — ปรับโค้งทางเชื่อมตามกระดานอ้างอิง
23 พฤศจิกายน 2569

สำหรับแอปที่ใช้กระดานอ้างอิงภาพรุ่น 22 พฤศจิกายน 2569 แล้ว
ปรับโค้งทางเชื่อมล่างสองฝั่ง คงวงในและโลโก้ขนาดล่าสุด รวมพื้นหลังรุ่นล่าสุด
ไม่เปลี่ยนกติกา ลำดับช่อง หรือข้อมูลห้อง

วิธีอัปเดต
1. สำรองโปรเจกต์
2. แตก ZIP แล้ววางไฟล์ต่อไปนี้ในโปรเจกต์ที่มี package.json ตามตำแหน่งเดิม:
   components/PhotoBoard.jsx
   lib/board-display.mjs
   public/flow-garden-board-spacious-v2.svg
   แทนที่เฉพาะไฟล์ ไม่ลบโฟลเดอร์เดิม
3. Commit และ push ไป GitHub ที่เชื่อม Cloudflare
4. รอ Cloudflare deployment ขึ้น Success
5. รีเฟรช Ctrl+F5 หรือปิดเปิดหน้าใหม่บนมือถือ

ไม่ต้องรัน SQL ไม่ต้องแก้ Firebase หรือ wrangler.jsonc
ห้องที่ใช้กระดานรุ่นใหม่ไม่ต้องสร้างใหม่ ห้องกระดานรุ่นเก่ายังคงเดิม
ตรวจภาพเรนเดอร์จาก PhotoBoard แล้ว ยังไม่ได้ทดสอบการกดเล่นในเบราว์เซอร์จริงหรือ deploy
