Flow Club — แสดงระบบมือถือ iOS / Android / 24 พฤศจิกายน 2569

แสดงมือถือ · iOS หรือ มือถือ · Android
ใช้ข้อมูลที่เบราว์เซอร์รายงาน ไม่ใช่การตรวจยืนยันฮาร์ดแวร์
ถ้าระบุระบบไม่ได้ แสดงมือถือเหมือนเดิม
iPad/แท็บเล็ต และ PC ยังคงแสดงประเภทเดิม
ไม่เปลี่ยนการแนะนำอุปกรณ์สำหรับ Master
ไม่แก้ตัวหมาก Safari ในแพ็กนี้

ติดตั้ง
1. สำรองไฟล์เดิม
2. แตก ZIP แล้วแทนที่ทั้ง 3 ไฟล์ตามโฟลเดอร์:
   lib/device.mjs
   components/DeviceBadge.jsx
   app/page.jsx
3. Commit/push ไป GitHub ที่เชื่อม Cloudflare แล้วรอ deployment Success
   ต้อง deploy ทั้ง frontend และ Worker ตามกระบวนการ build เดิม เพราะ Worker ใช้ lib/device.mjs ตรวจค่าที่รับด้วย
4. ให้ผู้เล่นแต่ละคนรีเฟรชหน้าเกม เพื่อโหลดโค้ดใหม่และส่งข้อมูลอุปกรณ์
5. ข้อมูลใหม่ปรากฏให้คนอื่นในห้องเห็นตามรอบอัปเดตเกม
ไม่ต้องรัน SQL ไม่ต้องสร้างห้องใหม่ ไม่ต้องแก้ Firebase/wrangler.jsonc

ผู้เล่นที่ยังไม่โหลดแอปเวอร์ชันใหม่อาจยังแสดงเพียงมือถือ
ข้อมูลเป็นอุปกรณ์ล่าสุดที่รายงาน ไม่ใช่ตัวบอกสถานะออนไลน์
ทดสอบการจำแนกอุปกรณ์ 8 กรณีแล้ว ยังไม่ได้ทดสอบบน iPhone จริง
