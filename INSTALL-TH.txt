FLOW CLUB — อัปเดตกระดานโปร่งขึ้น / 23 พฤศจิกายน 2569

สำหรับแอปที่ติดตั้งกระดานอ้างอิงภาพรุ่น 22 พฤศจิกายน 2569 แล้ว
แพ็กนี้เป็นไฟล์แก้ไขเฉพาะส่วน ไม่ใช่ซอร์สแอปทั้งชุด

สิ่งที่เปลี่ยน
- เพิ่มระยะห่างระหว่างวงในกับวงนอกจาก 15 เป็น 48 หน่วย
- ปรับทางเชื่อมโค้งต่อเนื่องและมุมช่องให้มน
- ย่อและย้ายหมู บ้าน กราฟ และเครื่องคิดเลขออกจากแนวช่อง
- ใช้พิกัดแสดงผลเดียวกันสำหรับช่องและรูปผู้เล่น
- คงพื้นหลังโทนเดิม ลำดับช่อง และกติกาเดิม

วิธีอัปเดต
1. สำรองโปรเจกต์ปัจจุบันไว้ก่อน
2. แตกไฟล์ ZIP นี้
3. คัดลอกไฟล์ต่อไปนี้ลงโฟลเดอร์โปรเจกต์ที่มี package.json โดยรักษาชื่อโฟลเดอร์และแทนที่ไฟล์เดิม:
   components/PhotoBoard.jsx
   lib/board-display.mjs
   public/flow-garden-board-spacious-v2.svg (ไฟล์ใหม่ ต้องเพิ่มด้วย)
   ไม่ต้องลบโฟลเดอร์ components, lib หรือ public เดิม
4. หากใช้ GitHub เชื่อม Cloudflare ให้ commit และ push ทั้งสามไฟล์
   หรืออัปโหลดไฟล์ใน GitHub ตามตำแหน่งเดิม แล้ว commit changes
5. รอ Cloudflare build/deploy แสดง Success
6. เปิดแอปแล้วรีเฟรช Ctrl+F5 หรือปิดและเปิดหน้าใหม่บนมือถือ

ไม่ต้องรัน SQL ไม่ต้องเปลี่ยน Firebase หรือ wrangler.jsonc
ห้องที่ใช้กระดานรุ่นใหม่อยู่แล้วเห็นหน้าตาใหม่หลังรีเฟรช
ห้องเก่าที่ใช้กระดานรุ่นเก่ายังคงใช้กระดานเดิม
ไม่จำเป็นต้องสร้างห้องใหม่สำหรับห้องที่ใช้กระดานอ้างอิงภาพอยู่แล้ว

การตรวจสอบ
- Build ผ่าน
- ตรวจพิกัดทั้ง 48 ช่องและขอบเขตรูปผู้เล่นผ่าน
- ตรวจภาพที่เรนเดอร์จาก PhotoBoard ตัวจริงแล้ว
- ยังไม่ได้ทดสอบการกดเล่นผ่านเบราว์เซอร์จริงหรือ deploy ขึ้นระบบจริง
