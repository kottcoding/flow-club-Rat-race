FLOW CLUB — ปรับจุดเชื่อมวงนอกและขยายวงใน / 23 พฤศจิกายน 2569

สำหรับโปรเจกต์ที่ติดตั้งกระดานอ้างอิงภาพรุ่น 22 พฤศจิกายน 2569 แล้ว
รวมการจัดภาพตกแต่งจากอัปเดตก่อนหน้าไว้ด้วย

สิ่งที่เปลี่ยน
- ย้ายทางเชื่อมล่างซ้าย/ขวาไปเชื่อมขอบด้านนอกของช่องตามลูกศร
- ขยายรัศมีวงในจาก 190 เป็น 215 และเพิ่มขนาดตัวอักษร
- เอาวงเส้นตกแต่งสีน้ำเงินที่ล้อมวงในออก
- ย้ายตำแหน่งรูปผู้เล่นและปุ่มค้นหาตำแหน่งให้ตรงวงในที่ขยาย
- ไม่เปลี่ยนลำดับช่องหรือกติกา

วิธีติดตั้ง
1. สำรองโปรเจกต์ปัจจุบัน
2. แตก ZIP แล้วนำไฟล์ทั้ง 3 ไฟล์ไปวางในโปรเจกต์ที่มี package.json:
   components/PhotoBoard.jsx
   lib/board-display.mjs
   public/flow-garden-board-spacious-v2.svg
   รักษาโครงสร้างโฟลเดอร์และแทนที่ไฟล์เดิม ไม่ลบโฟลเดอร์เดิมทั้งโฟลเดอร์
3. Commit และ push ไป GitHub ที่เชื่อม Cloudflare
4. รอ Cloudflare build/deploy ขึ้น Success
5. รีเฟรช Ctrl+F5 หรือปิดและเปิดหน้าแอปใหม่บนมือถือ

ไม่ต้องรัน SQL และไม่ต้องเปลี่ยนค่า Firebase หรือ wrangler.jsonc
ห้องที่ใช้กระดานรุ่นใหม่นี้อยู่แล้วไม่ต้องสร้างใหม่
ห้องรุ่นเก่ายังใช้กระดานเก่าตามเดิม
ภาพ preview.png เรนเดอร์จาก PhotoBoard ตัวจริง ยังไม่ได้ทดสอบการกดเล่นผ่านเบราว์เซอร์จริง
