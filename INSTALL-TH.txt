23 พฤศจิกายน 2569

ใช้กับแอปที่ติดตั้งกระดานอ้างอิงภาพรุ่น 22 พฤศจิกายน 2569 แล้ว
รวมการขยายวงในและปรับภาพตกแต่งจากอัปเดตก่อนหน้าไว้ด้วย

1. สำรองโปรเจกต์ปัจจุบัน
2. แตก ZIP และคัดลอกไฟล์ 3 ไฟล์ตามโฟลเดอร์เดิมในโปรเจกต์ที่มี package.json:
   components/PhotoBoard.jsx
   lib/board-display.mjs
   public/flow-garden-board-spacious-v2.svg
   แทนที่เฉพาะไฟล์ ไม่ลบทั้งโฟลเดอร์
3. Commit และ push ไป GitHub ที่เชื่อม Cloudflare
4. รอ deployment ขึ้น Success
5. รีเฟรช Ctrl+F5 หรือปิดเปิดหน้าใหม่บนมือถือ

ไม่ต้องรัน SQL ไม่ต้องแก้ Firebase หรือ wrangler.jsonc
ไม่มีการเปลี่ยนกติกาหรือลำดับช่อง
ห้องกระดานรุ่นใหม่ไม่ต้องสร้างใหม่ ห้องกระดานเก่ายังคงรูปแบบเดิม

ตรวจภาพจากการเรนเดอร์ PhotoBoard และ build แล้ว
ยังไม่ได้ทดสอบการกดเล่นในเบราว์เซอร์จริง หรือ deploy ขึ้นแอปจริง
