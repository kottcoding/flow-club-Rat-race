FLOW CLUB — MASTER + DEVICE LABELS — 21 พฤศจิกายน 2569

ไฟล์อัปเดตนี้รวม Master รุ่นก่อนและการแสดงประเภทอุปกรณ์ล่าสุด ใช้กับโปรเจกต์เดิมรุ่นล่าสุด

สิ่งที่เพิ่ม
- แสดงประเภทมือถือ / แท็บเล็ต-iPad / PC-Notebook ข้างข้อมูลผู้เล่นในห้องรอและกรอบชื่อระหว่างเกม
- แสดงประเภทอุปกรณ์ในแถบ Master และรายการเลือกผู้เล่นด้วย
- อุปกรณ์ที่ยังไม่รายงานหรือระบุไม่ได้ แสดงว่า ไม่ทราบอุปกรณ์
- เป็นประเภทที่ตรวจจับโดยประมาณจากเบราว์เซอร์ ไม่ใช่ชื่อรุ่น ยี่ห้อ หรือสถานะออนไลน์
- รวมโน้ตบุ๊ก Windows/Mac และคอมพิวเตอร์ไว้ใน PC
- ไม่ใช้ขนาดหน้าต่างเป็นตัวตัดสิน จึงไม่กลายเป็นมือถือเพียงเพราะย่อหน้าต่าง PC
- พยายามรองรับ iPad ที่รายงานตัวเป็น Mac โดยดูข้อมูลการสัมผัสประกอบ
- โหมด Desktop site, เครื่องพับได้ และการปกปิดข้อมูลเบราว์เซอร์ อาจทำให้ประเภทคลาดเคลื่อน
- ส่งเฉพาะรหัสประเภท 4 ค่า ไม่เก็บ User-Agent, หมายเลขเครื่อง หรือรุ่นเครื่อง
- ใช้ข้อมูลนี้เพื่อแสดงป้ายเท่านั้น ไม่ใช้ตัดสินสิทธิ์ Master หรือบังคับรูปแบบหน้าจอ
- รายงานเมื่อเข้าห้อง/โหลดหน้า และเมื่อกลับมาแท็บเกม ไม่มีการ polling อุปกรณ์ต่อเนื่อง
- ถ้าเปิดบัญชีเดียวกันในห้องเดียวกันหลายอุปกรณ์ จะแสดงประเภทที่รายงานล่าสุด ไม่ใช่รายการทุกอุปกรณ์

วิธีติดตั้ง
1. สำรองโปรเจกต์เดิม
2. แตก ZIP แล้ววางโฟลเดอร์ app, components, lib, db, tests ทับไฟล์เดิม โดยรักษาโครงสร้าง
3. หากติดตั้ง Master และ Execute db/004-teaching.sql แล้ว ไม่ต้องรัน SQL เพิ่มสำหรับอุปกรณ์
   หากยังไม่ได้ติดตั้ง Master ให้ทำตาม README-MASTER-TH.txt ที่แนบ โดย Execute db/004-teaching.sql ก่อน Deploy
4. Commit ไฟล์ขึ้น GitHub เดิมเพื่อ Deploy ด้วย Cloudflare pipeline เดิม
5. หลัง Deploy สำเร็จ ให้ผู้เล่นทุกคนรีเฟรชหน้าเว็บและเข้าห้อง จะเห็นป้ายประเภทอุปกรณ์

การตรวจสอบ
ผ่านชุดทดสอบ 19 รายการ รวมการตรวจจับตัวอย่างมือถือ/iPad/Android tablet/PC จอสัมผัส
ทดสอบ API ว่ารายงานได้เฉพาะตัวเอง ปฏิเสธค่านอกประเภท และรายงานค่าเดิมไม่เพิ่ม revision
ยังไม่ได้ทดสอบอุปกรณ์จริงทุกชนิด และยังไม่ได้ Deploy ขึ้นเว็บ Production
