แพตช์แยกจาก Master: แสดงประเภทและเลขการ์ดบนหน้าการ์ดที่เปิด
ตัวอย่าง โอกาสเล็ก · การ์ดเลขที่ 02
รองรับโอกาสเล็ก โอกาสใหญ่ จ่ายซะ และซื้อ–ขาย ใช้เลขเดียวกับคลังการ์ดของแอป
เลขไม่ได้หมายถึงลำดับครั้งที่จั่ว และอาจซ้ำกันข้ามประเภท ต้องเทียบประเภทพร้อมเลข

- ผู้เล่นเห็นป้ายเหนือชื่อการ์ด และ Master เห็นด้วยในหน้าติดตาม/เปิดดูเอง
- โหมดผู้ชมแสดงประเภทและเลขการ์ดปัจจุบันด้วย
- ประวัติเปิดการ์ดใหม่ระบุประเภทและเลข ทำให้ตรวจย้อนหลังได้
- ประวัติเก่าไม่ถูกแก้ย้อนหลัง เพราะชื่อการ์ดบางชื่อใช้กับหลายหมายเลข
- ไม่มีการเปลี่ยนวิธีสุ่ม การสับสำรับ ราคา หรือกติกาซื้อขาย
- เหตุการณ์บนกระดานและธุรกิจ Fast Track ที่ไม่มีหมายเลขการ์ดจะไม่ถูกใส่เลขสมมุติ

วิธีอัปเดต
1. สำรองโปรเจกต์เดิม
2. แตก ZIP และวางโฟลเดอร์ components และ lib ทับไฟล์เดิมที่รากโปรเจกต์
3. Commit ไป GitHub เดิมและรอ Cloudflare Deploy สำเร็จ
4. ให้ทุกคนรีเฟรชหน้าเว็บ แล้วทดสอบเปิดการ์ด จะเห็นประเภทพร้อมเลขเหนือชื่อ
ไม่ต้องรัน SQL หรือแก้ wrangler.jsonc เพิ่ม
แพตช์นี้ใช้กับแอปเดิมรุ่นล่าสุดและติดตั้งแยกหลังแพตช์ Master ได้

ตรวจสอบ: ชุดทดสอบการ์ด สำรับผ่าน API และ Master รวม 23 รายการผ่าน
ยังไม่ได้ Deploy ขึ้น Production
