FLOW CLUB — MASTER MODE — 21 พฤศจิกายน 2569

แพ็กเกจนี้เป็นไฟล์อัปเดตสำหรับโปรเจกต์ Flow Club รุ่นล่าสุดที่มีระบบชื่อไม่ซ้ำแล้ว
ไม่ใช่โปรเจกต์เต็ม และยังไม่ได้ Deploy ขึ้นเว็บจริง

วิธีอัปเดต
1. สำรองไฟล์โปรเจกต์เดิมก่อน โดยเฉพาะ app/page.jsx และ app/api/game/route.js
2. แตก ZIP แล้วนำโฟลเดอร์ app, components, lib, db และ tests วางทับในรากโปรเจกต์เดิม โดยคงโครงสร้างโฟลเดอร์
   ไม่ต้องเปลี่ยน wrangler.jsonc, Firebase หรือฐานข้อมูลเดิม
3. ต้องติดตั้งตารางใหม่ก่อน Deploy:
   เปิด Cloudflare > D1 > ฐานข้อมูล flow-club-db ที่แอปใช้อยู่ > Console
   เปิดไฟล์ db/004-teaching.sql แล้วคัดลอกคำสั่งทั้งหมดไป Execute
   มี CREATE TABLE IF NOT EXISTS สองตาราง ไม่มีคำสั่งลบข้อมูลห้องหรือผู้เล่น
   ถ้า Console รับได้ทีละคำสั่ง ให้ Execute แต่ละ CREATE TABLE แยกกัน
   หรือใช้ Terminal ที่รากโปรเจกต์ (เลือกวิธีใดวิธีหนึ่ง):
   npx wrangler d1 execute flow-club-db --remote --file=db/004-teaching.sql
   ถ้าชื่อฐานข้อมูลของคุณต่างออกไป ให้ใช้ชื่อที่กำหนดใน wrangler.jsonc เดิม
4. อัปโหลดไฟล์ที่เปลี่ยนไป GitHub repository เดิม และ Commit เพื่อให้ Cloudflare สร้างและ Deploy ตามการตั้งค่าเดิม
5. รอ Deploy สำเร็จ จากนั้นให้ผู้เล่นทุกคนรีเฟรชหน้าเว็บ รวมถึงผู้สอน
   ผู้เล่นที่ยังเปิดแอปเวอร์ชันเก่าอยู่จะส่งรายละเอียดหน้าจอให้ Master ไม่ได้

วิธีใช้งาน
- ห้องเริ่มต้นปิดการสอน ไม่มีการส่งหน้าจอเพิ่มเติม
- ผู้สร้างห้องกด เปิดการสอน ได้ทั้งก่อนเริ่มและระหว่างเล่น
- จัดการสิทธิ์ Master: เลือกผู้เล่นที่จะเป็นผู้สอนเพิ่มได้หลายคน และถอนสิทธิ์ได้
- ผู้สอนกด เข้าโหมด Master แล้วเลือกผู้เล่นจากรายการ
- เริ่มที่โหมดติดตาม: แสดงส่วนเกมที่ผู้เล่นกำลังใช้งาน รวมถึงจำนวนที่กำลังกรอกและสูตรคำนวณ
- เปิดดูเอง: ดูงบการเงินและข้อมูลเกมได้โดยไม่เปลี่ยนหน้าจอของผู้เล่น
- จำลองหน้าจอผู้เล่น: ใช้ความกว้างและระดับขนาดตัวอักษรของผู้เล่นเป็นแนวทาง เลือกพอดีจอหรือขนาดอ่านชัดได้
- ปรับตามจอฉัน: จัดส่วนที่กำลังดูให้เหมาะกับหน้าจอของผู้สอน
- กลับไปเล่น: ยุติการติดตามก่อนกลับมาทำรายการของตัวเอง
- ทุกคนเห็นว่าห้องเปิดการสอน และผู้ถูกดูเห็นชื่อผู้สอนที่กำลังติดตาม
- เมื่อไม่สอนแล้ว ผู้สร้างห้องกด ปิดการสอน เพื่อหยุดระบบนี้สำหรับทั้งห้อง

ขอบเขตของเวอร์ชันนี้
- เป็นหน้าจอจำลองจากสถานะส่วนเกม ไม่ใช่วิดีโอหรือภาพหน้าจอจริงทุกพิกเซล
- ปุ่มทำธุรกรรมใน Master ใช้งานไม่ได้และไม่ส่งคำสั่งแทนผู้เล่น
- ไม่มีการขอแชร์หน้าจออุปกรณ์ และไม่ส่งหน้าโปรไฟล์ การเข้าสู่ระบบ รหัสห้อง หรือแท็บอื่น
- รองรับการ์ด ธนาคาร งบการเงิน แท็บการคำนวณ รายละเอียดที่เปิด และคลังการ์ด
- การอัปเดตขึ้นกับเครือข่ายและรอบตรวจสอบ ผู้เล่นต้องเปิดหน้าเกมไว้
- เมื่อปิดการสอน ไม่มีการ polling สำหรับระบบสอนเพิ่ม
- เมื่อเปิดแต่ยังไม่มีผู้ดู ตรวจสอบผู้สนใจทุกประมาณ 3 วินาที แต่ไม่ส่งรายละเอียดหน้าจอ
- เมื่อมีผู้ดู ตรวจสอบหน้าจอประมาณ 0.75 วินาที และ Master รับข้อมูลประมาณทุก 2 วินาที
- สถานะหน้าจอแยกจาก revision เกม จึงไม่ทำให้ซื้อขายชนกันเพียงเพราะมีคนดู
- หากเครือข่ายขาด สถานะดูหมดอายุภายในประมาณ 15 วินาที และภาพที่เก่ากว่า 20 วินาทีไม่ถูกแสดงเป็นภาพปัจจุบัน
- ข้อมูลหน้าจอล่าสุดถูกแทนที่ ไม่มีประวัติหน้าจอสะสม ปิดการสอนหรือเปลี่ยนสิทธิ์จะล้างข้อมูลการติดตามของห้อง

ทดสอบหลังติดตั้ง
1. เปิดห้องสองอุปกรณ์หรือสองเบราว์เซอร์ แยกผู้สร้างห้องกับผู้เล่น
2. เริ่มเกม เปิดการสอน แล้วเข้า Master เลือกผู้เล่นอีกคน
3. ให้ผู้เล่นกรอกจำนวนกู้ 20,000 โดยยังไม่กดยืนยัน: Master ควรเห็น 20,000 และสูตร แต่กดกู้แทนไม่ได้
4. เปลี่ยนแท็บงบการเงิน/การคำนวณ และเปิดรายละเอียดสินทรัพย์ ตรวจว่าติดตามได้
5. กลับไปเล่น แล้วตรวจว่าปุ่มของตัวเองกลับมาใช้งานตามสถานะเกม
6. ให้สิทธิ์และถอนสิทธิ์ Master จากผู้เล่นอีกคน ตรวจว่าเข้าได้เฉพาะตอนมีสิทธิ์
7. ปิดการสอน ตรวจว่า Master ถูกปิดและผู้เล่นกลับสู่เกมปกติ
8. ลองมือถือแนวตั้ง/แนวนอนและแท็บเล็ตด้วย ปรับตามจอฉันและจำลองหน้าจอผู้เล่น

การตรวจสอบระหว่างพัฒนา
- ชุดทดสอบสิทธิ์ Master, หน้าจอ read-only, ส่งค่าที่กรอก, ถอนสิทธิ์, ปิดระบบ รวมกับระบบชื่อ/เข้าห้อง/สมาชิก ผ่าน 18 รายการ
- ทดสอบส่งค่า 20,000 ระหว่างสอง session ในเบราว์เซอร์ท้องถิ่นแล้ว
- ยังไม่ได้ทดสอบบน iPad/มือถือจริง หรือฐานข้อมูล Production

หากขึ้น TEACHING_SETUP_REQUIRED ให้ตรวจว่ารัน SQL ในฐานข้อมูลเดียวกับ binding DB ของ Worker
