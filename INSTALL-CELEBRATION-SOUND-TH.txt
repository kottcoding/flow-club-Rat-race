ออกจากสนามแข่งหนูไป Fast Track: Kids Cheering.mp3
มีผู้ชนะทำความฝันสำเร็จ: Victory Sound Effect.mp3
ไฟล์ต้นฉบับคัดลอกโดยไม่ดัดแปลงเป็น public/sounds/kids-cheering-v1.mp3 และ victory-v1.mp3
เล่นเมื่อสถานะเปลี่ยนจริง ไม่เล่นซ้ำจากการรีเฟรชหรือดึงข้อมูลเดิม
หากสำเร็จทั้งสองเหตุการณ์พร้อมกัน ใช้เสียงชัยชนะเป็นหลัก
รองรับปิดเสียงและปรับระดับเสียงเดิม

1. สำรองโปรเจกต์ และ Pull origin ใน GitHub Desktop ให้เรียบร้อย
2. แตก ZIP คัดลอกโฟลเดอร์ lib, public และ tests ทับใน repository ระดับเดียวกับ package.json
3. Commit แล้ว Push origin
4. รอ Cloudflare deploy สำเร็จ เปิดเว็บไซต์แล้วกด Ctrl+F5
5. เปิดเสียงในเมนูเสียง แล้วตรวจเมื่อผู้เล่นเข้าสู่ Fast Track หรือชนะเกม

ชุดนี้รวมไฟล์ MP3 จากชุดอัปเดตเสียงก่อนหน้า
ไม่ต้องแก้ SQL, Firebase หรือ wrangler.jsonc
ยังไม่ได้ deploy ไปยังเว็บไซต์จริง
