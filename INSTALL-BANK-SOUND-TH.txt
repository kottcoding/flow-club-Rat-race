เสียงยืนยันดังหลังเซิร์ฟเวอร์ยืนยันรายการสำเร็จ และไม่เล่นซ้ำจากการดึงข้อมูลเดิม
เสียง Click.mp3 ของปุ่มและเสียงเหตุการณ์อื่นยังทำงานตามเดิม

1. สำรองโปรเจกต์ปัจจุบัน และ Pull origin ใน GitHub Desktop ให้เรียบร้อย
2. แตก ZIP แล้วคัดลอกโฟลเดอร์ lib, public และ tests ทับใน repository ระดับเดียวกับ package.json
3. ตรวจ Changes แล้ว Commit เช่น Update bank success sound
4. กด Push origin และรอ Cloudflare build/deploy สำเร็จ
5. เปิดเว็บไซต์แล้วกด Ctrl+F5 เปิดเสียงในเมนูเสียง และทดลองกู้เงิน คืนเงินกู้ หรือชำระหนี้ที่มีอยู่
6. หากเสียงไม่มา ตรวจว่า /sounds/bank-success-v1.mp3 บนโดเมนเว็บไซต์เปิดได้ และไม่ได้ปิดเสียงแท็บ
