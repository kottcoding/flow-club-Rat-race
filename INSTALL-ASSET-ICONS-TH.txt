ไม่เปลี่ยนมูลค่า จำนวน กระแสเงินสด หรือกฎการเล่น

1. สำรองโปรเจกต์ และ Pull origin ให้เรียบร้อย
2. แตก ZIP คัดลอก components, lib และ public ทับ repository ระดับเดียวกับ package.json
3. Commit แล้ว Push origin
4. รอ Cloudflare deploy ผ่าน กด Ctrl+F5 แล้วเปิดสินทรัพย์และหนี้สิน

ไม่ต้องแก้ SQL, Firebase หรือ wrangler.jsonc
ใช้กับโค้ดปัจจุบันที่มีระบบเสียงและล็อกห้องแล้ว
ยังไม่ได้ deploy เว็บไซต์จริง
