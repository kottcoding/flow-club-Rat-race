แก้ไขเสียงซ้ำ — 14 พฤศจิกายน 2026

สิ่งที่พบจากการตรวจโค้ด
- ตัวจับคลิกส่วนกลางเล่น Click.mp3 บนปุ่มที่มีเสียงรายการสำเร็จอยู่แล้ว
- คำตอบ POST ใช้สถานะทันทีโดยไม่ตรวจรุ่น เทียบกับ polling ที่อาจได้รับสถานะใหม่กว่าก่อนแล้ว ทำให้สถานะถอยหลังและเหตุการณ์ถูกตรวจพบซ้ำ
- บันทึกซื้อและขายในชุดข้อมูลเดียวกันอาจเรียกไฟล์ money เดียวกันสองรอบ

สิ่งที่แก้
- ปุ่มซื้อ ขาย ธนาคาร บริจาค ทอยลูกเต๋า และเลือกการ์ด ใช้เสียงเหตุการณ์โดยไม่ซ้อน Click
- ปุ่มทั่วไป รวมถึงเสร็จแล้ว/ไม่ขายและจบตายังใช้ Click
- ปฏิเสธสถานะรุ่นเก่าในผลรายการ และระบบเสียงรับแต่ละ revision เพียงครั้งเดียว
- ผู้ชมได้รับ revision สำหรับตรวจเสียงซ้ำด้วย และหยุดเสียงห้องผู้เล่นที่ไม่ได้แสดงขณะชม
- แต่ละชุดเสียงเล่นไฟล์เดียวกันเพียงครั้งเดียว
- ทอยลูกเต๋าแล้วตกช่องยังมีเสียงลูกเต๋า ตามด้วยเสียงตกช่อง ซึ่งเป็นคนละเหตุการณ์

ติดตั้ง
1. สำรอง repository และ Pull origin ให้เรียบร้อย
2. แตก ZIP คัดลอก app, components, lib, public และ tests ทับใน repository ระดับเดียวกับ package.json
3. Commit แล้ว Push origin
4. รอ Cloudflare build/deploy สำเร็จ แล้วกด Ctrl+F5
5. ทดสอบซื้อ ขาย กู้ คืนเงินกู้ ชำระหนี้ เลือกการ์ด และทอยลูกเต๋า เปิดเพียงหนึ่งแท็บระหว่างตรวจเสียง

ไม่ต้องแก้ SQL, Firebase หรือ wrangler.jsonc
ชุดนี้รวม MP3 ที่อัปเดตมาก่อนหน้า
ยังไม่ได้ deploy เว็บไซต์จริง
