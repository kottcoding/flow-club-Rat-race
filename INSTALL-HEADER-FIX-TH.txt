แก้เมนูเสียงและแถบด้านบนบนมือถือ — 17 พฤศจิกายน 2026

สาเหตุที่พบในโค้ด
- Header มีความสูงตายตัว แต่ nav สามารถขึ้นบรรทัดใหม่ ทำให้ปุ่มล้นลงมาทับเนื้อหา
- Header และกระดานมี stacking context โดยเมนูเสียงเพิ่ม z-index ภายในอย่างเดียวไม่พอ

การแก้ไข
- Header สูงตามเนื้อหา บนมือถือโลโก้อยู่แถวบน เมนูจัดเป็น 2 คอลัมน์
- ปุ่มเสียง โปรไฟล์ วิธีเล่น และภาษามีพื้นที่กดอย่างน้อย 44 พิกเซล
- ยกชั้น Header เหนือกระดาน ป๊อปอัปเสียงไม่ถูกบังและไม่ล้นขอบจอมือถือ
- ปิดเมนูเสียงด้วยการแตะด้านนอกหรือกด Escape
- เอา backdrop-filter ของ Header ออกเพื่อไม่ให้รบกวนตำแหน่งของปุ่มปรับขนาดข้อความแบบ fixed

ติดตั้ง
1. สำรองโปรเจกต์ และ Pull origin ให้เรียบร้อย
2. แตก ZIP คัดลอก app และ components ทับ repository ระดับเดียวกับ package.json
3. Commit และ Push origin
4. รอ Cloudflare deploy สำเร็จ แล้วกด Ctrl+F5 บนคอมพิวเตอร์ / โหลดหน้าใหม่บนมือถือ
5. เปิดเมนูเสียง ลองปรับระดับเสียง และกดโปรไฟล์ ทดสอบทั้งแนวตั้งและแนวนอน
