Emojis — วิธีอัปเดต Flow Club

ฟีเจอร์
- ปุ่ม 😊 Emojis เหนือกระดาน เฉพาะช่วงกำลังเล่น
- เมนูภาพล้วน 12 แบบ เรียง 4 คอลัมน์ × 3 แถว ไม่มีชื่อใต้ภาพ
- กดส่งได้แม้ไม่ใช่ตาของตัวเอง รอ 3 วินาทีระหว่างการส่ง
- ผู้เล่นและผู้ชมเห็นภาพเคลื่อนไหวพร้อมชื่อผู้ส่งประมาณ 3 วินาที
- ผู้ชมส่งไม่ได้ ไม่มีเสียงเพิ่ม และภาพไม่ขวางการคลิกกระดาน
- เห็นได้สูงสุด 3 ภาพพร้อมกัน หากเกินจะแสดง 3 ภาพล่าสุด
- ดึงข้อมูลประมาณทุก 1 วินาที จึงอาจเห็นต่างเวลากันเล็กน้อยตามเครือข่าย
- ไม่เล่นย้อนหลังตอนเปิดหน้า รีเฟรช หรือกลับจากแท็บอื่น
- อุปกรณ์ที่ตั้งลดการเคลื่อนไหวจะแสดงภาพนิ่ง 3 วินาทีแทน

สำคัญ: เพิ่มตาราง D1 ก่อน deploy
1. เปิด Cloudflare แล้วเลือกฐานข้อมูล D1 ของแอป (flow-club-db)
2. เปิด Console สำหรับรัน SQL
3. เปิดไฟล์ db/003-room-reactions.sql ใน ZIP คัดลอกคำสั่งทั้งหมด
4. วางใน Console แล้วกด Execute / Run
5. ตรวจด้วย SELECT name FROM sqlite_master WHERE type='table' AND name='room_reactions';
   ต้องได้ชื่อ room_reactions
SQL นี้สร้างตารางใหม่ ไม่ลบหรือแก้ข้อมูลห้องเดิม รันซ้ำได้

ติดตั้งโค้ด
1. สำรอง repository และ Pull origin ให้เรียบร้อย
2. แตก ZIP คัดลอก app, components, lib, public, db และ tests ทับ repository ระดับเดียวกับ package.json
3. Commit เช่น Add animated room emojis แล้ว Push origin
4. รอ Cloudflare build/deploy ผ่าน แล้วกด Ctrl+F5 ทุกเครื่อง
5. เปิดห้องที่กำลังเล่น ทดลองส่งจากผู้เล่นหนึ่งคน ตรวจภาพจากอีกเครื่องและหน้าผู้ชม

ชุดนี้ใช้ต่อจากเวอร์ชันล่าสุดที่มีระบบล็อกห้องและเสียงอยู่แล้ว
ไม่ต้องแก้ wrangler.jsonc หรือ Firebase
ตารางอีโมจิแยกจากสถานะเกม การส่งไม่เปลี่ยนตา เงิน หรือ revision เกม
ทดสอบอัตโนมัติชุดรวม 26 รายการผ่าน และ build ผ่าน
ยังไม่ได้รัน SQL หรือ deploy ไปเว็บไซต์จริงแทนผู้ใช้
