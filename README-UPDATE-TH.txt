Flow Club — ธีมฤดูกาลและวันสำคัญ / 18 พฤศจิกายน 2569

ชุดนี้เป็น PATCH สำหรับโปรเจกต์ Flow Club เวอร์ชันล่าสุด ไม่ใช่แอปแยก

วิธีอัปเดตผ่าน GitHub + Cloudflare Workers Builds
1. สำรองโปรเจกต์เดิมหรือสร้าง commit เก็บไว้ก่อน
2. แตก ZIP นี้ในเครื่อง
3. คัดลอกโฟลเดอร์ app, components, lib, public, scripts, tests จาก ZIP ไปทับในโฟลเดอร์โปรเจกต์เดิม โดยรวมโฟลเดอร์เข้าด้วยกัน ไม่ลบไฟล์อื่น
4. หากใช้ GitHub เว็บ: เปิด repository เดิม > Add file > Upload files แล้วอัปโหลดโฟลเดอร์เหล่านี้ให้เส้นทางตรงกับ root เดิม ไม่อัปโหลด ZIP ทั้งก้อน
5. Commit การเปลี่ยนแปลงเข้า branch ที่ Cloudflare ใช้ deploy
6. รอ Cloudflare Workers & Pages > flow-club-rat-race > Deployments แสดงว่า deployment สำเร็จ ใช้ build/deploy command เดิมของโปรเจกต์
7. เปิดเว็บและกด Ctrl+Shift+R จากนั้นเปิดเมนู “บรรยากาศ”
8. ทดลองสลับ อัตโนมัติ / ฤดูกาลเท่านั้น / Flow Club เดิม และ ปิด / เบา แล้วรีโหลดเพื่อตรวจว่าจำค่าได้

ไม่ต้องรัน SQL ไม่ต้องเปลี่ยน Firebase หรือ wrangler.jsonc ชุดนี้ไม่มีไฟล์ credentials หรือฐานข้อมูล
หากมีการแก้ app/page.jsx หรือ app/layout.tsx เพิ่มเองหลังเวอร์ชันล่าสุด ให้ merge การ import Atmosphere, CSS และการวาง component ใน nav แทนการทับไฟล์ทั้งไฟล์
