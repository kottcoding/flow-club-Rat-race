PATCH สำหรับโปรเจกต์ล่าสุดที่ติดตั้งธีม Atmosphere v2 แล้ว

วิธีอัปเดต GitHub + Cloudflare
1. สำรองโปรเจกต์เดิมหรือ commit เก็บไว้
2. แตก ZIP แล้วคัดลอกโฟลเดอร์ app, components, lib และ tests ไปยัง root โปรเจกต์เดิม รวมโฟลเดอร์และทับเฉพาะไฟล์ชื่อเดียวกัน ไม่ลบไฟล์อื่น
3. หากอัปโหลดผ่าน GitHub เว็บ ให้เลือก Add file > Upload files อัปโหลดโฟลเดอร์ที่แตกแล้ว ไม่อัปโหลด ZIP ทั้งก้อน และตรวจเส้นทาง app/api/game/route.js ให้ตรงของเดิม
4. Commit เข้า branch ที่ Cloudflare ใช้ deploy
5. ไป Cloudflare Workers & Pages > flow-club-rat-race > Deployments รอ deploy สำเร็จ ใช้ build/deploy command เดิม
6. รีเฟรชแอปด้วย Ctrl+Shift+R
ไม่ต้องรัน SQL ไม่ต้องแก้ wrangler.jsonc หรือ Firebase
หากมีการแก้โค้ดอื่นหลังเวอร์ชันล่าสุด ให้ merge ไฟล์แทนการทับทั้งไฟล์ โดยเฉพาะ app/page.jsx และ app/api/game/route.js

พฤติกรรม
- ตรวจชื่อห้องทุกห้องที่ยังมีอยู่และยังไม่ครบ 7 วันนับจากเวลาสร้าง ทุกสถานะ รวมจบเกม ไม่จำกัดเฉพาะ 80/200 ห้องแรก
- ห้องครบ 7 วันหรือถูกลบแล้วใช้ชื่อใหม่ได้; ห้องเก่าไม่มี createdAt ใช้ updated ตามระบบหมดอายุเดิม
- ห้องเก่าชื่อซ้ำยังอยู่ตามเดิม แต่สร้างชื่อซ้ำเพิ่มไม่ได้
- ตัดช่องว่างหัวท้าย รวมช่องว่างซ้อน ไม่แยกตัวพิมพ์ใหญ่เล็ก และปรับ Unicode ให้เป็นรูปมาตรฐาน
- กดสร้างห้องชื่อซ้ำมีป๊อปอัป “ชื่อห้องนี้ถูกใช้แล้ว” ปุ่มแก้ไขชื่อห้องกลับไปเลือกข้อความในช่องเดิม
- ชื่อผู้เล่นตรวจเฉพาะผู้ที่ยังอยู่ในห้องเป้าหมาย ใช้ซ้ำต่างห้องได้ กลับเข้าห้องด้วยตัวตนเดิมได้
- ผู้เล่นชื่อซ้ำจะอยู่ในป๊อปอัปเข้าร่วมห้องพร้อมแจ้งเตือนและเลือกช่องชื่อให้แก้ ยังไม่เพิ่มเข้าเกม
- ผู้ที่ยังไม่เลือกห้องไม่มีการจองชื่อ แสดงคำอธิบายใต้แบบฟอร์ม
- ใช้ SQL เขียนแบบมีเงื่อนไขเพื่อตรวจว่ารายชื่อห้องยังตรงกับข้อมูลที่ตรวจแล้ว หากมีห้องเพิ่มพร้อมกันจะอ่านและตรวจใหม่ ไม่ใช้การตรวจจาก browser อย่างเดียว
