Flow Club — Atmosphere Effects v2 / 18 พฤศจิกายน 2569

แก้สาเหตุเอฟเฟกต์สังเกตยาก:
- เดิมขยับภาพเพียง 10px ใน 18–23 วินาที จึงดูคล้ายภาพนิ่ง
- เพิ่มอนุภาคเคลื่อนไหวตามขอบจอ: ใบไม้ ฝน หยดน้ำ กระดาษโปรย และแสงอุ่น ตามกลุ่มธีม
- เพิ่มระดับ ชัดเจน และปุ่ม ทดลองเอฟเฟกต์ 5 วินาที ซึ่งปิดเมนูให้เห็นเอฟเฟกต์และกลับสู่ค่าเดิมเมื่อครบเวลา
- การเปิดรายละเอียดการ์ด/สินทรัพย์ทั่วไปไม่หยุดเอฟเฟกต์อีกต่อไป
- ยังคงพักเมื่อเปิดเมนู กรอกข้อมูล แสดงกล่องโต้ตอบ Emoji/ฉลอง หรือซ่อนแท็บ
- ธีมรำลึกและสารทจีนยังคงภาพนิ่ง; reduced-motion ของเครื่องยังได้รับการเคารพ
- ไม่เพิ่มเสียงบรรยากาศและไม่เปลี่ยนกติกา

วิธีอัปเดต
1. สำรองโปรเจกต์เดิม
2. แตก ZIP แล้วรวมโฟลเดอร์ app, components, lib, public, scripts, tests เข้ากับโปรเจกต์เดิมและทับไฟล์ตรงกัน ไม่ลบไฟล์อื่น
3. Commit ขึ้น GitHub branch ที่ Cloudflare deploy รอ Deployments สำเร็จ
4. กด Ctrl+Shift+R จากนั้น บรรยากาศ > ภาพเคลื่อนไหว > ชัดเจน
5. กด ทดลองเอฟเฟกต์ 5 วินาที หรือปิดเมนูแล้วมองขอบซ้ายและขวาจอ
6. หากเครื่องเปิด Reduce motion เมนูจะบอกเหตุผลที่ใช้ภาพนิ่ง

รวมไฟล์ธีมจาก v1 ครบ ไม่จำเป็นต้องลง v1 ก่อน แต่ต้องใช้โปรเจกต์ Flow Club ล่าสุด
ไม่ต้องรัน SQL ไม่ต้องแก้ Firebase หรือ wrangler.jsonc
วันที่ตามรายการที่เจ้าของแอปกำหนด; การตั้งค่าจำเฉพาะเบราว์เซอร์เครื่องนี้
การตรวจสอบ: tests วันที่ 6 รายการผ่าน; ตรวจ build อีกครั้งก่อนส่ง ไม่มีการ deploy production ในขั้นตอนนี้
