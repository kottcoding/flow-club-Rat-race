FLOW CLUB — กระดานอ้างอิงภาพจริง — 22 พฤศจิกายน 2569

แพตช์สำหรับโปรเจกต์ Flow Club เดิมรุ่นล่าสุดที่มีระบบชื่อห้อง/ชื่อผู้เล่นไม่ซ้ำ
รวมไฟล์ Master + ป้ายอุปกรณ์ + เลขการ์ดล่าสุดแล้ว ไม่ต้องติดตั้ง ZIP สองชุดนั้นซ้ำ
ไม่ใช่โปรเจกต์เต็ม และยังไม่ได้ Deploy ไป Cloudflare ให้โดยอัตโนมัติ

สิ่งที่เปลี่ยน
- กระดานวงใน 24 ช่อง: โอกาส 12, รับเงินเดือน 3, ซื้อขาย 3, จ่ายซะ 3, บริจาค/มีลูก/ลดพนักงานอย่างละ 1
- วงนอก 48 ช่อง: ความฝัน 23, ธุรกิจ 18, รับกระแสเงินสด 3, บริจาค/ภาษี/ถูกฟ้อง/หย่าร้างอย่างละ 1
- เส้นทางวงนอกวิ่งรอบวงในและต่อออกขอบกระดานตามลำดับภาพจริง
- ใช้พื้นหลังและภาพตกแต่งเดิมของ Flow Club ไม่เปลี่ยนเป็นพื้นหลังกระดานสีม่วงในภาพถ่าย
- ธุรกิจแต่ละช่องใช้ชื่อ เงินลงทุน และกระแสเงินสดเฉพาะช่อง ไม่สุ่มธุรกิจตัวอย่างเดิม
- เหมืองทอง น้ำมันรัสเซีย และเครื่องครัว: จ่ายเงินก่อนทอย 1 ลูก รับรายได้ตามเงื่อนไข หากไม่สำเร็จเงินลงทุนไม่คืน
- IPO: ลงทุน 250,000 แล้วทอย 6 หรือ ลงทุน 500,000 แล้วทอย 5–6 รับเงินขายทันที 5,000,000 เมื่อสำเร็จ ไม่มีหุ้นคงเหลือหรือรายได้รายเดือน
- แก้ราคาหอศิลป์เป็น 1,750,000 และแก้ชื่อสวนพร้อมสกายวอล์ค / อาหารค่ำกับนักร้องหรือวงโปรด
- แตะทุกช่องเพื่อดูรายละเอียดและภาพอ้างอิง เพิ่มขยาย 1–3 เท่า เต็มจอ และตำแหน่งของฉัน
- ตัวผู้เล่นซ้อนอยู่ในช่องเดียวกัน เจ้าของตาอยู่บนสุด
- บันทึกธุรกิจ Fast Track ที่ซื้อและผลลงทุนไว้ในแผงการเงิน
- คงสูตรเงินเริ่มต้น Fast Track / รายได้เริ่มต้น / เป้าหมายเดิม และรับเงินเดือนอัตโนมัติเช่นเดิม
- โหมดผู้ชมและ Master ใช้กระดานตามรุ่นของห้อง

สำคัญ: ห้องที่สร้างก่อนติดตั้งยังใช้กระดานและราคาชุดเดิมจนจบ รวมถึงห้องเก่าที่รอผู้เล่น
ต้องสร้างห้องใหม่หลังอัปเดตจึงจะได้กระดานใหม่ เพื่อไม่ย้ายตำแหน่งหรือเปลี่ยนเงื่อนไขระหว่างเกม

วิธีติดตั้งทีละขั้น
1. สำรองโฟลเดอร์โปรเจกต์เดิม หรือ Commit งานเดิมใน GitHub Desktop ก่อน
2. แตก ZIP นี้ จะเห็น app, components, lib, public, db, scripts และ tests
3. คัดลอกโฟลเดอร์เหล่านี้ไปวางที่รากโปรเจกต์เดิม ตำแหน่งเดียวกับ package.json และ wrangler.jsonc
   เลือกแทนที่เฉพาะไฟล์ชื่อซ้ำ เป็นการรวมโฟลเดอร์ ห้ามลบโฟลเดอร์เดิมทั้งโฟลเดอร์
4. ไม่ต้องเปลี่ยน wrangler.jsonc, database_id, Firebase หรือ package.json
   กระดานใหม่นี้ไม่ต้องเพิ่มตาราง D1
   เฉพาะผู้ที่ยังไม่เคยติดตั้ง Master: เปิด Cloudflare > D1 > ฐานข้อมูลของแอป > Console
   แล้ว Execute เนื้อหา db/004-teaching.sql หนึ่งครั้งก่อนใช้ Master
   ถ้าเคยติดตั้งแล้ว ข้ามขั้นตอน SQL นี้ได้
5. ใน GitHub Desktop ตรวจรายการ Changed files > ใส่ชื่อ Commit เช่น Update photo board > Commit > Push origin
6. เปิด Cloudflare > Workers & Pages > flow-club-rat-race > Deployments รอ Build/Deploy เป็น Success
   ใช้คำสั่ง Build/Deploy เดิมของโปรเจกต์ ไม่ต้องเปลี่ยนค่าการเชื่อมต่อ
7. ให้ผู้เล่นทุกคนรีเฟรชหน้าเว็บ บน PC ใช้ Ctrl+Shift+R
   รุ่นนี้ปรับ API_VERSION เป็น 4: หน้าเว็บเก่าจะถูกขอให้รีเฟรชก่อนทำรายการ เพื่อไม่ใช้กระดานผิดรุ่น
8. สร้างห้องใหม่แล้วตรวจว่าเห็นเส้นทางใหม่ แตะช่องธุรกิจและลองปุ่มขยาย
   ห้องเดิมต้องยังแสดงเส้นทางเดิมและข้อมูลเงินเดิม

ตรวจหลังอัปเดต
- สร้างห้องใหม่ 2 คน เริ่มเกม ทอย และตรวจว่าตัวผู้เล่นอยู่ช่องที่แสดงในเหตุการณ์
- แตะช่องวงใน/วงนอก เปิดภาพอ้างอิง และลองขยาย/กลับตำแหน่งตนเองบนมือถือ
- ช่อง IPO: ลงทุนแล้วรีเฟรช ต้องยังรอทอยธุรกิจ และรับผลได้เพียงครั้งเดียว
- ช่องธุรกิจธรรมดา: รายได้เพิ่มตรงกับช่อง และมีรายการในธุรกิจ Fast Track
- ลองผู้ชมและ Master: กระดานตรงกับห้อง และ Master ยังคงดูอย่างเดียว

การตรวจสอบก่อนส่ง
- ชุดทดสอบ 164 รายการผ่าน รวมกติกาเดิม กติกากระดานใหม่ ทุกหน้าลูกเต๋าธุรกิจ การรักษาห้องเก่า และ API ป้องกันทำรายการซ้ำ
- API ทดสอบด้วย SQLite ในหน่วยความจำ แทน Cloudflare D1 จริง
- Production build ผ่าน
- ตรวจภาพ SVG ที่เรนเดอร์จากหน้าแอปและแก้ข้อความวงในล้ำช่องแล้ว
- เครื่องมือควบคุมเบราว์เซอร์ขัดข้อง จึงยังไม่ยืนยันการกด UI/เต็มจอหรือหน้าจอมือถือจริง ควรลองตามรายการข้างต้นหลัง Deploy
- ไม่มีการแก้ไขข้อมูลห้องจริงหรือ Deploy Production ในขั้นตอนทดสอบนี้
