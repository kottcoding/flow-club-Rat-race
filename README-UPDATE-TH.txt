สิ่งที่ปรับ
- ชื่อช่องวงนอกเพิ่มจาก 8 เป็น 13 หน่วยใน SVG (ภาษาไทย เพิ่มประมาณ 62%)
- ตัวอักษรวงในเพิ่มจาก 9 เป็น 11 หน่วย
- ใช้ชื่อสั้นที่จัดบรรทัดไว้ ไม่ตัดคำกลางตัวเลข
- ซ่อนราคาและรายได้บนตัวกระดาน เพื่อลดความแน่นและให้ชื่อใหญ่ขึ้น
- แตะช่องเพื่อดูชื่อเต็ม ราคา รายได้ เงื่อนไข และภาพอ้างอิงได้เหมือนเดิม
- ต่อช่วงโค้งทั้งสองฝั่งเข้ากับขอบกระดานเป็นรูปช่องต่อเนื่อง แทนเส้นเชื่อมแยก
- ปิดช่องว่างระหว่างช่องวงโค้ง และจัดช่องขอบกระดานให้ต่อกัน
- คงพื้นหลัง จำนวนช่อง ลำดับช่อง กติกา และตำแหน่งผู้เล่นเดิมทั้งหมด

วิธีอัปเดต
1. สำรองโปรเจกต์เดิมหรือ Commit งานเดิมใน GitHub Desktop ก่อน
2. แตก ZIP นี้
3. คัดลอกโฟลเดอร์ components และ lib ไปวางทับในรากโปรเจกต์เดิม
   ตำแหน่งเดียวกับ package.json โดยรวมโฟลเดอร์และแทนที่ไฟล์ชื่อซ้ำ
   ไฟล์ที่ใช้จริงมี 2 ไฟล์:
   components/PhotoBoard.jsx
   lib/board-display.mjs (ไฟล์ใหม่ ต้องนำไปด้วย)
4. GitHub Desktop > ตรวจ Changed files > Commit > Push origin
5. รอ Cloudflare Build/Deploy เป็น Success แล้วให้ผู้เล่นรีเฟรชหน้าเว็บ
   บน PC ใช้ Ctrl+Shift+R

ไม่ต้องรัน SQL ไม่ต้องแก้ wrangler.jsonc, Firebase หรือ package.json
ห้องที่ใช้กระดานรุ่น 22 พ.ย. อยู่แล้วไม่ต้องสร้างใหม่ อัปเดตรูปลักษณ์หลังรีเฟรชได้เลย
ห้องเก่าก่อนรุ่นนั้นยังคงกระดานเก่าเพื่อรักษาเกมเดิม
